# numpy-pandas-viz-notes

This repository contains a compact Jupyter Notebook covering essential concepts and examples in:

- **NumPy** – numerical operations, arrays, broadcasting, etc.
- **Pandas** – dataframes, indexing, filtering, grouping, and manipulation.
- **Data Visualization** – using Matplotlib and Seaborn to plot and analyze data visually.

## ✨ Who is this for?

- Data science learners revisiting fundamentals
- Developers preparing for interviews
- Anyone needing a Python-based quick refresher on core data tools
